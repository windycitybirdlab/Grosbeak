# Grosbeak
An open-access horn microphone for bioacoustics specializing in capturing nocturnal flight calls of migratory birds.

## Build Materials
-	3D-printed Horn, Seal, and Grill using ASA Filament
-	Stainless M5 Screws
-	Windscreen mesh
-	Hydrophobic screen
-	Heavy-duty UV-resistant Rubber Band
